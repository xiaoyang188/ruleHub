# 简短回答

**没有。** RuleHub 是独立的社区索引与内容站点，**不属于、也不代表** Anthropic、OpenAI 或任何 AI 公司。我们未获上述公司官方授权使用其商标做背书。

# RuleHub 是什么？

RuleHub 帮助开发者：

- 搜索与浏览开源 **Agent Skills**（`SKILL.md`）
- 阅读 AI 编程相关的教程与洞察文章
- 发现 VibeCoding 项目与行业动态

我们提供安装 Prompt、GitHub 链接与文档说明，**不**分发闭源模型或官方插件包。

# 与 Claude / ChatGPT / Codex 的关系

| 产品 | 关系 |
|------|------|
| Claude Code | 支持加载 Skills；RuleHub 索引的 skill 多来自社区 GitHub |
| ChatGPT / Codex | 部分 skill 格式通用；是否可用取决于各客户端实现 |
| Anthropic / OpenAI 官网 | 无隶属关系；请以官方文档为准 |

名称、Logo 仅用于说明兼容性，不暗示官方合作。

# 内容与安全责任

- 索引的 skill **均来自第三方 GitHub 仓库**
- RuleHub **不审计**每一行代码；安装前请自行审查
- 详见 [如何评估 GitHub Skills 的安全性](/insights/evaluate-github-skills)
